# Пепел и Чары: Королевства

Пиксельная RPG-песочница для Android: выживание среди нежити, магия, стройка как в Terraria, королевства, гильдия, любовь и семья.

**Сайт игры:** https://ctapblu25rus.github.io/Pepel-Kingdoms/

- Скачать: [PepelKingdoms_v3.2.apk](download/PepelKingdoms_v3.2.apk) (Android 7.0+)
- Версия для разработчика: [PepelKingdoms_v3.2_DEV.apk](download/PepelKingdoms_v3.2_DEV.apk)
- Идеи и баги — в разделе [Issues](https://github.com/cTaPblu25rus/Pepel-Kingdoms/issues)

Сайт — статические файлы (`index.html`, `style.css`, `app.js`). Тексты, обновления и ссылка на YouTube правятся в `content.js`; данные о предметах и существах — в `data.js`.

Авторы графики, звука и музыки — в [CREDITS.txt](CREDITS.txt).
